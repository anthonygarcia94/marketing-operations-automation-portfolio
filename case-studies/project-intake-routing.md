# Project Intake Routing

## The problem

Incoming marketing projects needed to reach the correct owner consistently. Manual assignment created repetitive administrative work and depended on someone remembering the ownership rules for each type of request.

## My role

I translated the team's existing ownership model into workflow logic. Before automation, that meant understanding the request categories, who was responsible for each category, where exceptions existed, and what information had to be present before routing could occur.

## Solution

The resulting workflow evaluates new project intake against defined project types and ownership rules, then assigns the appropriate owner automatically.

The purpose was not to automate decision-making that required human judgment. It was to remove a repetitive routing step where the decision had already been defined by the team.

## Development and validation

I used AI-assisted development to help translate the routing requirements into automation logic. The workflow was tested using dry-run behavior so proposed changes could be reviewed before updates were allowed to reach the live project-management system.

After validation, scheduled execution allowed the routing logic to operate without someone manually running the process.

## Outcome

The system made intake more consistent and reduced dependency on manual assignment while preserving the team's underlying ownership structure.
