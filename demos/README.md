# Working Demos

These demos are independently recreated portfolio examples using fictional data. They demonstrate the kinds of operational patterns I design and automate without publishing employer production assets.

| Demo | Focus |
| --- | --- |
| [Project Intake Routing](project-intake-routing/README.md) | Configurable ownership rules, dry-run validation, manual-review exceptions, GitHub Actions |
| [Team Capacity Planning](team-capacity-planning/README.md) | Role-aware capacity assumptions and planning signals |
| [Request Reporting & Archival](request-reporting/README.md) | Lifecycle classification, historical preservation, recurring reporting logic |
| [Project Risk Dashboard](project-risk-dashboard/README.md) | Task-level aggregation into a leadership health signal |

These examples intentionally favor readable, auditable logic over unnecessary complexity. In production, equivalent patterns may interact with work-management platforms through authenticated APIs and scheduled workflows.
